Usage

The Explore Signals window has two areas:

  • The side panel on the left contains the Loaded Files list, the Channels list, and the buttons for each tool.

  • The plot area on the right shows the current visualization.

The typical workflow is: load a file, select it in Loaded Files, choose channels, then filter, visualize, clean, or export it.

Loading EEG/ExG data

Opening files

To load data:

  1. Navigate to:

    File > Open

  2. Select one or more files. Supported formats are .csv and .bdf.

Each file is added to the Loaded Files section. While a file is being read, it is shown with the label (loading…) and cannot be selected. Large recordings load in the background, so you can keep working while they load.

The File menu

Companion files for CSV recordings

Explore .csv recordings consist of several files that are matched by file name. Keep them together in the same folder.

File Required Purpose

<name>_ExG.csv

Yes

The ExG signal. This is the file you open.

<name>_Meta.csv

Recommended

Sampling rate and channel information. Without it, the data may not load correctly.

<name>_Marker.csv

Optional

Event markers, shown on the time-domain plot.

If you rename the files, for example after exporting filtered data, keep the _ExG.csv, _Meta.csv, and _Marker.csv endings so that the files are still matched.

Importing from a BIDS dataset

To load a recording from a BIDS dataset:

  1. Navigate to:

    File > Import BIDS

  2. Click Browse BIDS Root and select the root folder of the dataset.

  3. Select the Subject, Session, Task, and Device. The Recording Info box shows details of the selected recording.

  4. Click Import to File List.

Both the standard BIDS layout written for .bdf and .edf files and the CSV layout under derivatives/csv/ written by Explore Signals can be imported. Events from the dataset are loaded as markers.

Importing a recording from a BIDS dataset

Removing files

To remove files from the list, select them in Loaded Files and click Delete Files. You can select several files with Ctrl or Shift.

Delete Files only removes the files from the current session. Nothing is deleted from your disk.

Channel selection

To choose which channels are used:

  1. Select a file in the Loaded Files section.

  2. Check or uncheck channels in the Channels section.

  3. Use one of the visualization, cleaning, or export actions.

To quickly enable or disable all channels, use the Select All and Clear All buttons above the Channels section.

Only the checked channels are plotted, cleaned with ASR, and exported.

Choosing channels in the side panel

Applying filters

To apply filters:

  1. Select the file you want to filter in the Loaded Files section.

  2. Navigate to:

    Filters > Apply Filters

  3. Fill in the filters you want to use. Leave a field empty to skip that filter.

  4. Click Apply.

Field Effect

Low Cutoff Frequency (Hz)

High-pass filter. Removes slow drift below this frequency.

High Cutoff Frequency (Hz)

Low-pass filter. Removes content above this frequency.

Notch Filter Frequency (Hz)

Removes line noise at this frequency, typically 50 Hz or 60 Hz.

Average Re-referencing

Re-references every channel to the average of all channels.

DC Offset Correction

Removes the constant offset from each channel.

The filtered data is added to the Loaded Files section as a new entry. Its name is based on the original file name and the filters that were applied. The original file is not changed.

The Apply Filters dialog

The time-domain viewer

Click Plot Time Domain to show the checked channels stacked above each other over time. Markers from the recording are drawn as vertical lines.

The viewer opens on the first 10 s of the recording, or on the whole recording if it is shorter. For recordings with many channels, it shows eight channels at a time. Scroll vertically or use the Channels control to see the rest.

Full screen and focus mode

Full-screen mode hides the menu bar and side panel so the plot fills the screen. Use it to review long recordings or many channels. Full screen is available for the time-domain plot. When you switch to another visualization, Explore Signals leaves full screen automatically.

To keep the menu bar but give the plot more room, hide only the side panel with Ctrl+B.

Annotations

Annotations let you mark spans of the recording while you review it:

  1. Click Annotate.

  2. Drag across the plot to mark a span. Click an existing annotation to select it.

  3. Click Annotations to open the list next to the plot. The list contains both the markers from the recording and your own annotations, which are marked with ✎.

In the list you can:

  • Search by label.

  • Click an entry to jump to it.

  • Double-click one of your annotations, or select it and click Rename, to change its label.

  • Click Delete, or press Del, to remove the selected annotation.

Markers from the recording are read-only. Markers with timestamps outside the recording are hidden, and the list shows how many were hidden.

A user annotation (pink span) and the annotation list
Annotations you create in the viewer are only kept while the plot is open. They are not saved when you export the file. Markers from the recording are always kept.

File and view information

Select File / view info… from the ⋯ menu to see:

  • The file format, file size, original start time, and sampling rate.

  • The total duration and the currently visible window.

  • The number of samples and annotations in view.

  • The minimum, maximum, and peak-to-peak value of each channel in µV.

By default, the channel values are calculated for the visible window. Select Whole recording to calculate them for the entire recording.

Select Save as PNG… from the ⋯ menu to save the current view as an image.

Artifact Subspace Reconstruction

Artifact Subspace Reconstruction, or ASR, removes high-amplitude, transient artifacts from multi-channel EEG. It learns what clean data looks like from a calibration window, then reconstructs the sections of the recording that deviate too far from it.

The ASR implementation in Explore Signals is based on parts of the open-source clean_rawdata plugin for EEGLAB.

Explore Signals applies ASR offline, to a recording you have already loaded. To apply ASR to a live signal while you are recording, use Explore Desktop and refer to the Artifact Subspace Reconstruction page in the Explore Desktop Guide.

If you plan to apply ASR and work with cleaned data, make sure you understand the method and its limitations. ASR may remove signal together with artifacts and performs better on certain types of data.

Before you apply ASR

  • Calibration data. ASR needs a calibration window. This should be a section of the data with as few artifacts as possible, ideally none.

  • Signal type. ASR is recommended for EEG signals. Output for other biosignals may be worse, for example if more signal than artifact is removed.

  • Number of channels. ASR requires multiple channels to clean signals effectively. Research suggests that ASR can achieve effective artifact removal for standard 20-channel EEG[1].

Standard deviation cutoff

The Cutoff field in the ASR pop-up is the standard deviation cutoff applied during cleaning. It sets the thresholds, relative to the calibration data, that decide which portions of the data are artifacts.

  • A lower cutoff causes more data to be recognized as artifacts.

  • A higher cutoff causes less data to be recognized as artifacts.

Typical values are:

  • 3.0 — aggressive

  • 5.0 — standard, and the default in Explore Signals

  • 20.0 — conservative, and the default in EEGLAB’s clean_rawdata plugin

Going below a cutoff of 3.0 is not recommended and is blocked by Explore Signals.

Calibration window

The Calibration Window sets the length of the data used for calibration. The default and minimum value is 30.0 s. For a cutoff of 20.0, the recommended calibration window is 60.0 s.

Calibration start

The Calibration Start sets the beginning of the calibration window.

The default setting is Auto, which places the start of the calibration window 20% into the recording. For example, if the recording is 120.0 s long and the calibration window is 30.0 s, the calibration window runs from 24.0 s to 54.0 s.

To choose the start yourself, select Manual start time and enter the starting second.

Applying ASR to a loaded file

To clean data using ASR:

  1. Select the file in the Loaded Files section and check the channels to clean.

  2. Click ASR Cleaning.

  3. Adjust the ASR parameters in the pop-up.

  4. Optional: click Load Preset to load a recommended preset.

Comparing the cleaned and original data

When cleaning is finished, Explore Signals opens a comparison view with the cleaned data drawn over the original data. The comparison view has the same Window, zoom, paging, and Sensitivity controls as the time-domain viewer. In addition, use Show to choose between:

  • Both

  • Cleaned only

  • Original only

Select Save as PNG… from the ⋯ menu to save the comparison as an image.

The ASR implementation applies a high-pass filter internally to correct for drift, so the cleaned signal is also zero-mean. If the original data is not filtered or not zero-mean, the two signals may not share the same baseline in the comparison view.

The cleaned data is added to the Loaded Files section and can be visualized, processed, and exported like any other file.

Original (blue) and cleaned (orange) data around a head-movement artifact

Exporting data

Original and processed data can be exported from the File menu.

To export data:

  1. Select the file you want to export in the Loaded Files section.

  2. Check the channels you want to export. Only the checked channels are written.

  3. Navigate to:

    File > Export

  4. Choose the file name and select .csv or .bdf as the format.

Explore Signals adds _ExG to the file name if it is not already there.

  • When exporting to .csv, markers are written to a matching _Marker.csv file.

  • When exporting to .bdf, markers are stored inside the file. The data is written in BDF+ format using 24-bit resolution.

Exporting to .bdf may cause a loss of precision of less than 0.1 µV for Mentalab recordings. Very small or very large values produced by filtering may be truncated or rounded.

When exporting to .bdf from a .csv file, the physical range of the signal is calculated from its minimum and maximum values. The signal looks as expected, but its values may be shifted and rescaled compared with the original.

To convert whole recordings or folders between formats without loading them, use the Convert / Process wizard. See Convert / Process wizard.

Repairing CSV recordings

If packets are dropped while recording with explorepy or Explore Desktop, the binary file from the Explore device memory can be used to repair the recorded .csv file.

To repair a recorded .csv file:

  1. Place the .csv file and the matching .BIN file in the same folder.

  2. Navigate to:

    Tools > Repair ExG .csv with .BIN

  3. Select the .csv file to repair.

  4. Click Repair.

The repaired file is saved in the same folder as the selected file. It has the same name, with _recovered_ExG added.
