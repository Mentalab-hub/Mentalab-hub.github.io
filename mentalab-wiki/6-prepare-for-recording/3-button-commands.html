Button Commands and Functions (marker, shutdown, reset)

The Explore amplifier is controlled through a single multifunction button. Different press durations and timings trigger different functions. LED signals provide confirmation for each action.

Power On

Action: Briefly press the button once while the amplifier is turned off.
LED Feedback: Device lights up (green/yellow/red, depending on battery status).
Result: Amplifier powers on and starts recording to internal memory by default.

  • If you hold the button too long, a pink light may appear instead of the battery status, indicating that an instant marker has been set. Try pressing the button more briefly.

Event Marker

Action: Briefly press the button during recording (device turned on).
LED Feedback: One-time light pink flash.
Result: An event marker is stored in the data (internal memory and online stream).

Shutdown

Action: Press and hold the button for ~3 seconds.
LED Feedback: Three red flashes.
Result: Amplifier powers down safely.

Always shut down the amplifier before connecting it to a computer via USB.

Memory Format (Reset)

Action: When device shows pink blinking at startup (indicating full memory), press the button three times in succession.
LED Feedback: Device confirms reset and resumes operation.
Result: Internal memory is formatted, and all stored recordings are permanently deleted.
