Troubleshoot macOs installation developer-could-not-be-verified

macOS

If you downloaded an older version of Explore Desktop for Mac, you might have to explicitly allow your operating system to launch the installer.

After double-clicking the downloaded .run file, follow these steps:

Allow the installer through macOS settings

  1. A warning will pop up informing you that the installer could not be opened because the developer could not be verified.

    Click Cancel to close the pop-up.

  2. Open the System Settings and go to:

    Privacy & Security

    Then scroll down to the Security section.

  3. A text indicating that the installer was blocked from running will show up here.

    Click Open Anyway.

  4. A new warning will pop up informing you again that the developer could not be verified.

    Click Open to launch the installer.

Override installer permissions using the terminal

In case this does not work, it is possible to override the permissions for the installer using the terminal.

After downloading the installer, follow these steps:

  1. Right-click on the downloaded file and click:

    Show Package Contents

  2. Navigate to the MacOSX folder and open a terminal there.

  3. Set the appropriate permission using the following command:

    chmod +x ExploreDesktopInstaller_x64

    This gives Explore Desktop permission to install.

  4. Right-click on the top-level file:

    ExploreDesktopInstaller_x64

    Then install Explore Desktop.

  5. Open:

    System Settings > Privacy & Security

    Make sure both permissions are enabled for Explore Desktop:

    • Bluetooth

    • Accessibility

  6. Remove the current Explore Desktop entry from both the Bluetooth and Accessibility sections and add it again.

  7. Right-click on the installed file:

    ExploreDesktop

    Then select Open.
