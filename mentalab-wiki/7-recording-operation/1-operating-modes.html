Operating modes

The Explore amplifier can operate in multiple modes depending on the connection and recording workflow. This flexibility ensures that data is captured reliably, whether used in standalone experiments or in real-time streaming environments.

Overview of Modes

  • Offline Mode – Records directly to internal memory for later retrieval.

  • Online Wireless Mode (Bluetooth) – Streams data via Bluetooth to a host device for live monitoring and recording.

  • Online Wired Mode (USB) – Connects to a host via USB-C for data transfer and tethered recording through isolators.

  • Auto-Fallback – If no Bluetooth connection is established within ~4 minutes, the amplifier automatically switches to offline recording mode.

The amplifier also records to internal memory during online recording as a backup. If you experience packet drops, you can use the offline recording to recover the complete recording.

Offline Mode

Description

The amplifier records data directly to its 8 GB internal flash memory. No host connection is required during the session.

Use cases

  • Mobile or outdoor recordings where carrying a computer/smartphone is not practical.

  • Long-term recordings where wireless stability cannot be guaranteed.

Data Access

After the session, connect the device to a computer via USB-C. Recordings can be converted and exported into formats such as .CSV, or .BDF+ using Explore Signals.

LED Indicator

  • Blue blinking four times per second (advertising).

  • Blue blinking once per second (connected).

Online Wireless Mode (Bluetooth)

Description

The amplifier streams data via Bluetooth Low Energy (BLE) to a paired host device. Real-time monitoring and configuration are possible. Note that the amplifier simultaneously writes data to its internal flash memory as a backup.

Use cases

  • Experiments requiring real-time visualization of EEG/ExG and IMU signals.

  • Situations where impedance must be checked before or during recording.

  • Protocols needing precise synchronization via software triggers or LSL.

Supported software

  • Explore Desktop (Windows/macOS/Linux)

  • Explore Mobile App (iOS/Android)

  • explorepy (Python integration with LSL and APIs)

LED Indicator

  • Blue blinking four times per second (advertising).

  • Blue blinking once per second (connected).

Online Wired Mode (USB)

Description

The amplifier streams data to the host computer via USB-C. Real-time monitoring and configuration are possible. A USB isolator ensures safe, low-noise data transfer.

Always use the provided USB isolator (labelled “UI”) when operating in this mode. Failure to do so introduces noise to the EEG recordings and compromises operation safety.

Use cases

Tethered operation in stationary paradigms, where high sampling rates and real-time data access are required.

Supported software

  • Explore Desktop (Windows/macOS/Linux)

  • explorepy (Python integration with LSL and APIs)

Limitations

The amplifier cannot simultaneously record to internal memory while operating in tethered USB streaming mode.The USB mode available with the Explore Pro is for streaming only, in this mode, you cannot retrieve recordings from the device’s memory. Always power on before connecting via USB.

Auto-Fallback Behavior

If the amplifier is switched on but no Bluetooth host connects within ~4 minutes, the device automatically switches to offline recording mode. If a Bluetooth connection is lost during online recording, the device falls back to offline mode, ensuring that no data is lost. If the amplifier is turned on and enough memory space is available, it will start recording data in its internal memory.
