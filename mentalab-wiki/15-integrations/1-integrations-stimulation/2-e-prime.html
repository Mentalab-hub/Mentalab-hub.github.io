E-Prime®

Prerequisites

Hardware

  • Mentalab Explore Pro Device: An Explore Pro biosignal acquisition system.

  • Mentalab Hypersync Add-on: This hardware is essential for accurately synchronizing LSL markers from E-Prime with the Explore device’s data stream.

  • Computer: To run E-Prime, LSL, and data recording software for the Explore device.

Software

  • E-Prime® 3

  • E-Prime® 3 LSL package file

  • E-Prime® 3 LSL samples

  • LabRecorder or alternative software that lets you record LSL streams

How it Works

  1. E-Prime: Runs experiments and can generate event markers during an experiment at onset time, response time, or current time.

  2. LSL package file: The LabStreamingLayer package file provides real-time streaming of data, including markers, with precise timestamps for E-Prime.

  3. Mentalab Hypersync: The Mentalab Hypersync suite is used to merge ExG data with event markers via LSL. Please follow the instructions delivered to you with your Hypersync hardware to achieve wireless, high-precision synchronization.

Integrating with E-Prime® via LSL

Consult the Mentalab Hypersync manual for achieving synchronisation between the Mentalab Explore amplifier and LSL.

To integrate with E-Prime® via LSL, follow the information published for E-Prime® on the PST website and the ReadMe on the GitHub repository for the LSL package file to add LSL functionality to your experiment set-ups:

  • LSL info page on the PST website

  • GitHub repository containing LSL package file for E-Prime®

The installation ReadMe and the LSL samples in the GitHub repository contain information on how to send markers via LSL at an object’s OnsetTime, stimulus response time, and at the current time. The markers can be used to synchronize with the Explore device if the device itself is synchronized using the Mentalab Hypersync suite.

Follow the installation ReadMe to add LSL markers to your experiment set-up according to your needs. The markers will be available as an LSL stream from any other script or software that makes use of LSL, like LabRecorder or custom scripts using LSL.

You can record the markers via LabRecorder, via the E-Prime stream as explained in the installation ReadMe, alongside the ExG datastream, named after the Explore device, from the synchronized Explore amplifier to record synchronized markers from an experiment and ExG data.

To ensure accurate synchronisation, you must use Mentalab Hypersync and follow the instructions provided alongside your Mentalab Hypersync hardware.

Alternative (Legacy) Methods: Wired Triggers

While LSL with Mentalab Hypersync is preferred as it enables fully wireless and highly accurate event marking, direct wired connections are also possible. Please refer to our Triggers and event markers page for further information.

For more information or support, contact support@mentalab.com.
